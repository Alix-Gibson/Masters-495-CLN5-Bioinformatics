# MAGeCK-iNC Analysis

This directory contains the MAGeCK-iNC analysis of the final filtered CRISPRi screen data for R1 and R2.

## Purpose

MAGeCK-iNC was used as a complementary statistical analysis of the CRISPRi screen to identify genes showing differential phenotypes between the lysotracker-sorted populations and the Diff population.

The analysis was performed separately for sequencing replicate R1 and R2.

## Input data

The analysis used the final MAGeCK sgRNA-level results generated from the **h1 Top5** CRISPRi library following the **Diff ≥20 read-count pre-filter**.

The two comparisons analysed were:

- `Upper_vs_Diff`
- `Lower_vs_Diff`

R1 and R2 were analysed independently.

## MAGeCK-iNC method

The analysis used a Python 3 compatibility port of MAGeCK-iNC v5.2. The statistical algorithm was retained from the original implementation.

For each comparison:

1. sgRNAs with a treatment mean read count ≤20 were excluded.
2. Non-targeting control (NTC) sgRNAs were identified.
3. Targeting sgRNAs were grouped by gene.
4. For each gene, sgRNAs were ranked by two-sided P value.
5. The three most significant sgRNAs for each gene were used to calculate the mean LFC.
6. A two-sided Mann–Whitney U test compared the P values of the three selected sgRNAs for each gene against the NTC sgRNA P-value distribution.
7. Pseudo-NTC groups were generated by randomly shuffling the NTC P-value/LFC pairs and selecting groups of five sgRNAs, with the best three used to calculate the pseudo-NTC phenotype and P value.
8. Phenotype values were median-centred using the NTC distribution.
9. A product statistic was calculated as:

   `product = epsilon × (-log10(P))`

10. An empirical FDR threshold of 0.05 was applied using the proportion of NTC observations above the product threshold.
11. Significant genes were exported as FDR-hit tables and visualised using volcano plots.

The random seed was set to `10` for pseudo-NTC generation.

## FDR threshold

An FDR threshold of **0.05** was used.

The product-statistic threshold was calculated independently for each replicate and comparison.

| Replicate | Comparison | Product threshold |
|-----------|------------|-------------------|
| R1 | Lower vs Diff | 15.9 |
| R1 | Upper vs Diff | 5.0 |
| R2 | Lower vs Diff | 15.3 |
| R2 | Upper vs Diff | 4.5 |

## Scripts

The analysis scripts used were:

- `Scripts/mageck_inc_Diff20_R1.py`
- `Scripts/mageck_inc_Diff20_R2.py`

The R1 and R2 scripts use the same statistical procedure, with the input and output directories changed to the corresponding replicate.
